# Church Youth Events Hub

A web platform designed to unite youth across churches by sharing upcoming events, enabling registrations, and fostering collaboration. Built with **HTML, CSS, JavaScript, Firebase, and Formspree**.

---

## 🚀 Features
- 📅 **Event Listings** – Display upcoming youth events with details.
- 📝 **Event Registration** – Register for events via Formspree and save records in Firebase Firestore.
- 🔍 **Event Filtering** – Search and filter events dynamically.
- 🙌 **Church Directory** – Showcase participating churches.
- 🖼️ **Gallery** – Share photos and highlights.
- 🔐 **Admin Dashboard** – Secure login (Email/Password + Google Sign‑In) with role‑based access (viewer, editor, super‑admin).

---

## 🔧 Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend/Database:** Firebase Firestore
- **Authentication:** Firebase Auth (Email/Password + Google Sign‑In)
- **Form Handling:** Formspree
- **Hosting:** GitHub Pages

## 🔒 Admin Access
- Admins must log in via **Email/Password** or **Google Sign‑In**.
- Roles are managed in Firestore (`admins` collection):
  - `viewer` → can only view registrations
  - `editor` → can manage events
  - `super-admin` → full access, including managing admins
